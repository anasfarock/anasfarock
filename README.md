---

I'm a Computer Science student at SZABIST, Islamabad, studying machine learning, software engineering, data structures, algorithms, and systems design. I work across the full stack Python, React, Next.js, TailwindCSS, and Express.js and I'm comfortable on both ends, building out a clean frontend or wiring up the backend logic behind it. Some of the things I've built include a portfolio analysis engine, a privacy-first Chrome ad blocker using Manifest V3, an event management app, and a TradingView indicator based. I'm also getting deeper into data science and machine learning, I've worked on projects like forest fire dataset analysis and I keep finding new ways to use Python to make sense of data.

Outside of personal projects, I've done internships at Techaccess Pakistan and Zayup, where I worked on IT infrastructure, system troubleshooting, and technical support. Those experiences taught me a lot that coursework just doesn't — dealing with real systems, real users, and real deadlines. I contribute to open-source and have multiple repos on GitHub, and I write and share across social platforms when I have something worth saying. I'm currently looking for new opportunities, I work well in teams, I pick things up fast, and I care about building things that actually work.
